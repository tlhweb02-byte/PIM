# 作图自动化在线中台 — 用户注册与宝尊扩图次数管理

本仓库在原有免费功能的基础上，为 **🎨 宝尊智能扩图 (ROSS)** 增加了
**用户注册 / 登录 + 免费体验次数** 机制：

- 其他功能（表格转化、图片压缩、字体下载、提效仪表盘）保持**免登录免费使用**；
- 宝尊智能扩图使用公司付费账号，**仅对注册用户开放**；
- 新用户注册赠送 **10 次免费体验**（每次成功生成扣 1 次）；
- **次数用完可充值**：微信扫码付款（100 次 = ¥10），提交交易单号、管理员确认后到账；
- 注册账号信息写入 **Google 表格**（与提效统计同一个表格，新增「用户账号」工作表）；
- **密码绝不存明文**：只保存加盐哈希（PBKDF2-SHA256，120000 次迭代）。

---

## 一、工作原理

| 项目 | 说明 |
|---|---|
| 账号存储 | Google 表格「提效中台数据统计」→ 新增「用户账号」工作表（自动创建） |
| 工作表列结构 | `username \| password_hash \| salt \| created_at \| used_count \| last_login_at` |
| 充值订单存储 | 同一表格 → 新增「充值订单」工作表（自动创建）：`order_id \| username \| amount \| quota \| status \| tx_id \| created_at \| confirmed_at` |
| 次数计算 | 剩余 = 免费 10 次 + 已确认购买次数 − 已用次数 |
| 免费次数 | 默认 10 次，可用 `AUTH_FREE_QUOTA` 配置 |
| 充值套餐 | 默认 100 次 = ¥10，可用 `WECHAT_PAY_QUOTA` / `WECHAT_PAY_PRICE` 配置 |
| 管理员 | `AUTH_ADMIN_USERNAMES`（逗号分隔）中的用户名**不限次数**，并在充值中心确认订单 |
| 鉴权 | 宝尊公司账号凭据仍只存在 .env / Streamlit Secrets，用户永远接触不到 |

## 二、充值流程（微信个人收款码）

1. 用户登录后进入 **「💰 次数充值中心」**，微信扫码付款（默认 ¥10 / 100 次）；
2. 付款后在微信「钱包 → 账单」找到该笔转账，复制【交易单号】粘贴到页面提交订单；
3. 管理员在「💰 次数充值中心」底部的**待确认订单**面板，先在自己微信账单核实到账，再点「✅ 确认到账」；
4. 确认后次数立即计入该用户剩余次数。

> 说明：个人微信收款码没有商户 API，无法自动验证到账，因此采用「提交交易单号 + 管理员人工核实」的半自动流程。如需全自动到账，可申请微信支付商户号后接入 API（需要企业/个体户资质）。

## 二、部署配置（Streamlit Cloud）

1. 把代码推送到 GitHub，在 Streamlit Cloud 上部署（原有 Secrets 保持不变：
   `gcp_service_account_base64`、`BAOZUN_*` 等）。
2. 打开网站 → 左侧「用户中心」→ **注册新账号**，先注册你自己的账号。
3. 回到 Streamlit Cloud 的 **Secrets** 里新增一行（把 `你的用户名` 换成刚注册的名字）：

   ```toml
   AUTH_ADMIN_USERNAMES = "你的用户名"
   ```

   保存后点 **Rerun**。这样你就是管理员，宝尊扩图**不限次数**。

4. 确认 Google 表格「提效中台数据统计」已共享给服务账号邮箱（提效统计能用就说明已共享）。
   「用户账号」工作表会在第一次注册时**自动创建**，无需手动建表。

> 本地运行：把同样的配置写进 `.env`（参考 `.env.example`）。

## 三、可配置项（.env / Secrets）

| 变量 | 说明 | 默认 |
|---|---|---|
| `AUTH_ADMIN_USERNAMES` | 管理员用户名，多个用英文逗号分隔 | 空 |
| `AUTH_FREE_QUOTA` | 新用户免费体验次数 | `10` |

## 四、次数扣减规则

- 点击「✨ 立即生成」→ 宝尊成功生成图片后，`used_count` +1；
- 生成失败 / 鉴权失败 **不扣次数**；
- 剩余次数用完会提示「免费试用次数已用完，请联系管理员」，无法继续使用宝尊扩图。

## 五、安全说明

1. **密码安全**：Google 表格里只有哈希值，拿不到也无法还原明文密码；
2. **表格权限**：请勿把「提效中台数据统计」表格的链接公开分享，只有服务账号邮箱有编辑权限；
3. **已知局限**：本方案为轻量级账号体系（无邮箱验证、无找回密码）。
   用户用完 10 次后理论上可再注册新账号，属于可接受范围；
   如需更严格风控（如邀请码注册），可在此基础上扩展。
